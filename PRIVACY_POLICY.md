# Privacy Policy

LibreTranslate Mobile stores user data locally on device to provide translation features.

## Data we store on-device

- Configured LibreTranslate server URLs and optional API keys
- Translation history
- Favorite translations
- App settings (theme, defaults, accessibility preferences)

## Data sent over network

Text, files, language-detection input, and an optional API key are sent to the selected LibreTranslate server: the default public instance or a custom URL. Translated files are downloaded from the URL returned by that server. Voice input may use the operating system’s speech recognition service.

## Data sharing

The app does not sell personal data and does not send analytics by default.

## Retention and deletion

- History and favorites remain on-device until user clears them.
- Users can clear history from Settings.
- Users can export history manually.

## Security

- Server URLs are user-controlled.
- HTTPS encrypts network traffic. HTTP is also supported for user-configured servers, including local instances.
- API keys are stored in ordinary app storage, not a dedicated secure credential store.

## Contact

For privacy requests, contact the app maintainer through the repository issue tracker.
