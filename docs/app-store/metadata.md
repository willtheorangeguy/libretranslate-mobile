## Description

LibreTranslate Mobile is an iOS-first translation app built for self-hosted LibreTranslate users. Configure your local or remote server URL and translate quickly with text input, speech input, and spoken output.

Features:

- Connect to custom LibreTranslate endpoints
- Real-time translation with language auto-detection
- Speech-to-text and text-to-speech
- Local SQLite history and favorites
- Search and export translation history
- Dark mode, text-size controls, and accessibility labels
