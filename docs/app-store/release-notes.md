# Release Notes

## 1.0.0

- Initial release of LibreTranslate Mobile
- Server setup for custom/self-hosted LibreTranslate instances
- Text translation with source/target language selection
- Auto-detect source language
- Speech-to-text input and text-to-speech output
- SQLite translation history and favorites
- Search and export/share history
- Theme mode (system/light/dark), text size controls, onboarding
- Added CI workflow for lint, typecheck, tests, and iOS build
